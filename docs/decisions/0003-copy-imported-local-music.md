# ADR-0003：复制导入本地音乐

- 状态：Accepted
- 日期：2026-08-04

## 背景

Android 的 Storage Access Framework 可以为用户主动选择的文档提供可持久化 URI 授权，但文件移动或删除后仍会失效；文件管理器 `ACTION_VIEW` 与其他 App 分享的 URI 通常只有临时授权。若本地库混用持久 URI、临时 URI 和文件路径，恢复、去重和错误处理会变得不可预测。

## 决定

所有进入 MoeKoe 本地音乐库的内容统一复制到 App 专属音乐目录。外部“打开方式”不是临时播放旁路，而是执行同一导入管线，并在文件落盘和 Room 提交成功后立即播放。

- App 内选择、设备扫描后选择、`ACTION_VIEW`、`ACTION_SEND` 和 `ACTION_SEND_MULTIPLE` 共用导入逻辑。
- 外部 URI 只在复制期间使用，不作为长期播放来源。
- 使用大小与 SHA-256 去重，相同内容复用已有副本。
- 导入副本随 App 卸载删除，不发布到公共 MediaStore。

## 理由

- 源文件移动、删除或授权收回不会破坏已导入音乐。
- 播放器只处理 App 管理的稳定来源。
- 外部打开与 App 内导入具有一致的错误、进度和去重语义。
- 不需要全文件访问或公共目录写入权限。

## 代价

- 同一音乐可能占用两份设备空间。
- 批量导入需要空间检查、复制进度、取消和残留清理。
- 卸载 App 会删除导入副本，必须在 UI 和文档中明确提示。
- 若未来需要跨 App 共享或卸载后保留，必须另行设计 MediaStore 导出功能。
