# 全屏播放器歌词页设计复刻与屏幕适配契约

状态：Accepted。确认日期：2026-08-08。适用范围：歌词内容、加载、无歌词、离线、错误、原文、音译及 `1.5×` / `2.0×` 字体状态。

本文把已确认的 [`07-player-lyrics.png`](mockups/07-player-lyrics.png) 与 [`23a` 至 `23h`](mockups/candidates/player-lyrics-v1/README.md) 转换为可执行的 Android 布局契约。页面视觉实现与歌词业务接线是两个独立切片：本契约先保证所有确认状态可由纯 UI 状态完整呈现，不以网络、缓存或逐字同步完成为前置条件。

## 权威顺序与基准语境

1. `07-player-lyrics.png` 决定正常“原文 + 翻译”状态的结构、坐标、比例、密度和层级。
2. `23a` 至 `23h` 只替换歌词视窗内容，分别决定加载、空、离线、错误、原文、音译和大字体状态；其余播放器区域不得重新解释。
3. [`PLAYER_LAYOUT_SPEC.md`](PLAYER_LAYOUT_SPEC.md) 决定与封面页共享的顶部栏、歌曲信息、进度和核心播放控制；[`13-player-artwork-palette.md`](../reference-audits/13-player-artwork-palette.md) 决定共享动态色与静态回退。
4. [`DESIGN_SYSTEM.md`](../DESIGN_SYSTEM.md) 决定触控区、语义和可访问性。后续接线只能替换状态来源，不得改变本页视觉合同。

基准画布为 `853 × 1844` 设计单位，简体中文、深色、系统字体倍率 `1.0×`、竖屏。目标逻辑宽度为 `390dp`，等比高度约为 `843dp`。

## 尺寸映射与 Insets

设设计画布宽度 `Dw = 853`，当前 Compact 页面容器宽度为 `W`：

```text
s = W / Dw
runtimeX = designX × s
runtimeY = designY × s
runtimeSize = designSize × s
```

- 同一页面内所有确认尺寸使用同一 `s`；禁止横纵分别缩放、按设备型号调参或把整张设计图作为运行时背景。
- 背景绘制到系统栏后方，顶部交互消费 `statusBars`，底部核心控制消费 `navigationBars` / `safeGestures`。
- Medium/Expanded 没有确认稿时使用最大 `480dp` 的居中单列，不拉宽歌词行长。
- 可见图标按确认稿缩放，点击语义区域至少 `48 × 48dp`。

## 页面固定骨架

| 区域 | 设计锚点 | 行为边界 |
| --- | --- | --- |
| 沉浸背景 | 与封面页完全相同的深色封面派生渐变 | 不为歌词页建立第二套取色器；无封面时使用同一静态回退 |
| 顶部控制 | 左侧向下收起、居中“正在播放”、右侧更多 | 与封面页共用组件和事件 |
| 歌词调节 | 右上圆形调节入口，中心约为 `(774, 264)` | 本切片提供视觉和语义；设置面板未接入前不伪造持久状态 |
| 歌词视窗 | `x = 72`、`y = 318`、宽约 `709`，内容居中 | 只此区域随歌词状态变化；不得推动下方播放器骨架 |
| 双页指示 | 约 `y = 1270`，歌词页第二点高亮 | 实现 Pager 后由真实页索引驱动 |
| 歌曲与播放区 | 标题、歌手、品质、收藏、进度、时间和五项核心控制 | 与封面页共享组件；歌词页不显示下载、加歌单、分享和队列四项次级动作 |

标准 `390 × 844dp` 页面不产生整页纵向滚动。歌词视窗与底部播放区是稳定的两个区域；歌词列表自己的滚动、跟随和点击 seek 在后续交互切片实现，不能让内容高度改变分页点或播放器控制的位置。

## 歌词内容层级

- 非当前原文：约 `15sp`、中等字重、低对比前景；行间距按设计坐标约 `44` 单位。
- 当前原文：约 `20sp`、SemiBold，当前逐字段由前景色过渡到动态强调色；未接逐字进度时允许用确定的预览进度呈现视觉状态。
- 翻译或音译：位于对应原文下方，约 `12sp`、正常字重、比原文更低对比；没有附加文本时不保留空行。
- 内容按歌词行整体居中；原文、翻译和音译不得拆成互不关联的滚动项。
- `1.5×` / `2.0×` 使用系统字体倍率自然放大，不缩小字号、不截断当前行；确认稿允许歌词视窗只显示更少行。

## 状态矩阵

| UI 状态 | 歌词视窗内容 | 可用动作 |
| --- | --- | --- |
| Loading | 居中进度环、“正在加载歌词”、“正在获取逐字歌词与翻译” | 不显示重试 |
| Empty | 无歌词图标、“暂无歌词”、“这首歌暂未提供同步歌词” | 重试 |
| Offline | 离线图标、“当前离线”、两行说明 | 重试 |
| Error | 错误图标、“歌词加载失败”、服务说明 | 重试 |
| Original | 原文行与当前行强调 | 行点击在后续接线中 seek |
| Translation | 原文、翻译与当前行强调 | 同上 |
| Phonetic | 原文、音译与当前行强调 | 同上 |

空、离线和错误为歌词区域内状态，始终保留顶部栏、分页点、歌曲信息、进度和播放控制。重试按钮使用全局 Filled 主按钮样式；不使用 Toast 或假成功状态代替恢复动作。

## 设计符合度与验收

1. 先以 `390 × 844dp`、Dark、`1.0×` 捕获 Translation 主态，归一化到 `853 × 1844`，与 `07-player-lyrics.png` 并排和叠加复核。
2. 固定锚点至少覆盖顶部三节点、调节入口、歌词视窗、分页点、歌曲信息、进度、时间和五项核心控制。
3. 再分别截图 Loading、Empty、Offline、Error、Original、Phonetic、`1.5×` 和 `2.0×`；状态切换只能改变歌词视窗内容和系统字体带来的自然排版。
4. 固定区域边界或中心偏差不得超过 `2` 个设计单位，相邻区域累计纵向漂移不得超过 `3` 个设计单位；字体栅格和 Material 图标笔画只作为遮罩差异。
5. 视觉切片通过后，业务切片再验证首次进入加载、切歌取消、重试、缓存、逐行跟随、手动滚动暂停跟随与点击 seek。
