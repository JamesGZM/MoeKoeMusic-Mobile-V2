# 全屏播放器交互原型

状态：基于已确认 `06`、`07`、`08` 号设计稿。建立日期：2026-08-05。

## 目的

本原型只验证全屏播放器的封面/歌词分页、纵向退出、播放控制、歌词定位、队列展开与系统返回优先级。它不是 Android 实现代码，不定义歌词协议、播放时序、正式文案、图标资源或持久化行为。

视觉结构、层级、密度与氛围分别以 [`06-player-cover.png`](../../mockups/06-player-cover.png)、[`07-player-lyrics.png`](../../mockups/07-player-lyrics.png) 和 [`08-player-queue.png`](../../mockups/08-player-queue.png) 为权威依据。原型内的 CSS 封面、SVG 图标、虚构歌曲和动效只用于交互检查，Compose 不得复制；正式图标按设计语义使用固定版本 Material Icons 或已批准资源。

## 本地查看

直接在浏览器打开 [`index.html`](index.html)。宽屏显示 `390 × 844dp` 手机视口和交互控制台；窄屏只显示播放器。

原型使用纯 HTML、CSS 和 JavaScript，无网络请求、第三方运行时、服务端、账号数据或本地持久化。

## 已验证交互

- 默认进入封面页；在封面/歌词区域横向拖动切换两页，页码指示同步更新。
- 进入歌词页时才表达歌词加载/跟随语义；点击歌词行更新播放进度，手动滚动后由实现层短暂暂停自动跟随。
- 下箭头或系统返回纵向退出到来源页面，保留队列、当前歌曲和播放进度；MiniPlayer 可重新展开。
- 队列作为当前播放器上的 `ModalBottomSheet`，遮罩、关闭、选歌、移除和安全区均不创建新的一级目的地。
- 返回优先级固定为“关闭队列 → 退出全屏播放器 → 返回来源页面”。
- 播放/暂停、上一首、下一首、收藏、音质和模式操作不会改变页面层级。
