# 登录流程交互原型

状态：历史交互参考。原型基于旧 `19` 至 `22` 号横向状态稿建立；这些旧稿的实现基线资格已于 2026-08-06 撤销。

## 目的

本原型只验证登录流程的状态切换、返回、提交锁定、二维码生命周期、安全验证隔离和多账号选择。它不是 Android 实现代码，不定义酷狗协议、正式文案、网络时序或持久化行为。

本原型不得继续定义页面结构、层级、密度或视觉形态。新版独立单状态确认稿见 [`login-v2`](../../mockups/candidates/login-v2/README.md)；只有确有必要验证交互时才更新原型。原型中的字符图标和近似图标只是历史占位，Compose 不得照搬。

## 本地查看

直接在浏览器打开 [`index.html`](index.html)。宽屏显示手机视口和状态控制台，`450px` 以下只显示手机界面。

原型完全本地运行，不发起网络请求，不保存账号、验证码、二维码或验证结果。页面中的账号、手机号和 ID 均为固定虚构示例。

## 验证范围

- 验证码、密码和扫码方式切换。
- 密码填写、显示切换、提交锁定、凭据错误和风控入口。
- 二维码生成、等待、已扫码、过期、失败和刷新。
- 短信二次验证、腾讯图形验证隔离、取消和成功后一次重试说明。
- 多账号显式选择、未选择禁用和登录成功返回。

## 非目标

- 不调用真实酷狗或腾讯服务。
- 不生成可扫描二维码，不模拟真实验证码算法。
- 不替代 Compose Preview、截图测试或真机验收。
- 不作为 Token、协议字段、错误码或正式文案来源。
