## 遮罩与人工复核

- 设计图中的时间、状态栏和导航栏示意不属于 App 资产；Preview 不提供真实系统 Insets，因此遮罩。
- 返回按钮由共享沉浸式 TopBar 根据真实状态栏 Insets 定位，Preview 中不把其纵向位置用于真机安全区结论。
- 生产 Hero 是从确认稿派生的独立无文字插画；叠加图只核对裁切框、主体构图和卡片覆盖关系，不要求插画像素逐点相同。
- 字体栅格、示意文案字形、输入动态值、倒计时和加载指示按规范遮罩；组件边界、起点、间距和基线区域不遮罩。

## 适用范围与剩余门禁

发送中、倒计时、已输入和提交中只改变已登记的动态区域，固定 Hero、Surface、分段控件、字段和主按钮锚点复用本报告；它们继续由独立截图基准覆盖。

本报告不证明密码、扫码、风险验证、多账号、IME、短高度、宽屏或真实系统 Insets 已完成设计符合度。API 29 真机只验证本轮交互与零滚动语义；真实验证码、密码、风控与跨设备扫码仍需用户主动验收。
