# 搜索结果页设计符合度复核

日期：2026-08-08。目标：[`03-search-results-v2.png`](../mockups/03-search-results-v2.png)。实现截图：`SearchContentScreenshot_Content_f2eee04b_0.png`（`390 × 764dp`）。

## 归一化方式

- 去除确认稿顶部系统状态栏和底部 App MiniPlayer；保留搜索页自身 Toolbar、Tab 与正文。
- 将确认稿页面内容按宽度归一化为 `1024px`，高度不足 Compose 画布的区域仅在底部补页面背景，不缩放或拉伸页面内容。
- 对相同画布生成并排、50% 叠加和差异图：[`side-by-side`](search-2026-08-08-side-by-side.png)、[`overlay`](search-2026-08-08-overlay.png)、[`diff`](search-2026-08-08-diff.png)。

## 复核结论

- 搜索框、六分类 Tab 分界线、歌手卡上下沿、歌曲区标题、四首歌曲行和歌单/专辑段起点已对齐确认稿结构与首屏密度。
- 搜索/清除/语音图标均为独立槽位；当前播放歌曲恢复 Primary 波形提示；横向内容使用真实独立位图资产和方形裁切。
- 可见差异限于平台字体栅格、Material 图标笔画以及重新生成的原创封面内容；没有缺失区块、错误滚动方向、固定占位高度或用生产假数据填充未迁移协议。

## 截图资产来源

- 工具：内置 ImageGen；确认稿只作为人物、配色和构图参考，最终文件保存于 `feature/search/src/main/res/drawable-nodpi/*_confirmed.png`。
- 提示集：分别生成无文字、无 Logo、无 UI 的方形日系动漫插画，包括青色双马尾虚拟歌手头像、近景歌曲封面、蓝紫舞台、深海，以及海滨、樱花、冰晶和晴空四张歌单封面；每张均为独立生成资产，不从确认稿裁图或从拼图切片。
- 用途限制：这些图片只服务 UI fixture 和静态视觉预览；真实搜索结果继续使用 Repository 返回的封面 URL，不把示例人物或歌单写入生产状态、领域模型或缓存。
