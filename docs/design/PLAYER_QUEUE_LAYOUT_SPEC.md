# 全屏播放器队列 Sheet 设计复刻与屏幕适配契约

状态：Accepted。确认日期：2026-08-08。适用范围：播放器内播放队列、当前项、空队列与长队列滚动状态。

本文把已确认的 [`08-player-queue.png`](mockups/08-player-queue.png) 转换为可执行的 Android 布局契约。队列继续使用 Material 3 `ModalBottomSheet`；设计稿决定其可见尺寸和内容样式，不以自定义浮层替换系统 Sheet 的遮罩、拖动、Insets 与返回处理。

## 权威顺序与基准语境

1. `08-player-queue.png` 决定 Sheet 顶边、圆角、拖拽柄、内容密度、当前项表达和背景层级。
2. [`PLAYER_LAYOUT_SPEC.md`](PLAYER_LAYOUT_SPEC.md) 与 [`PLAYER_LYRICS_LAYOUT_SPEC.md`](PLAYER_LYRICS_LAYOUT_SPEC.md) 决定 Sheet 下方播放器页面；打开队列不创建新目的地或第二份播放状态。
3. [`DESIGN_SYSTEM.md`](../DESIGN_SYSTEM.md) 决定最小触控区、排版与禁用状态；[`11-fullscreen-player-ui.md`](../reference-audits/11-fullscreen-player-ui.md) 决定系统返回、稳定 key 和状态所有权。
4. 设计稿中的歌曲、时长、来源和封面是视觉样例。生产实现只展示真实已有字段；缺失字段隐藏，不以固定样例冒充数据。

基准画布为 `853 × 1844` 设计单位，目标逻辑视口为 `390 × 844dp`。所有坐标使用同一宽度比例 `s = W / 853` 映射。

## Sheet 与系统行为

- Sheet 顶边约为 `y = 818`，对应标准视口约 `374dp`；可见高度约占视口 `56%`，最大高度不得超过审计允许的 `68%`。
- 顶部圆角约 `48` 设计单位，对应约 `22dp`；左右边与屏幕贴合，不增加卡片式外边距。
- 遮罩由 `ModalBottomSheet` 负责，底层播放器保持原位置且降低对比，不重新组合成截图背景。
- 拖拽柄可见尺寸约 `39 × 5dp`，其触控与拖动行为由系统 Sheet 负责。
- Sheet 消费 `navigationBars` / `safeGestures`；系统返回和向下关闭优先关闭 Sheet，再返回播放器或来源页面。
- Compact 深色基线中 Sheet 容器使用 `#222538`，当前项容器使用 `#2E304F`；两者来自 `08` 同画布取样，不能回退到偏蓝的播放器通用 Surface 色。

## 内容结构

| 区域 | 视觉合同 | 行为与数据边界 |
| --- | --- | --- |
| 标题行 | “播放队列”、真实数量、循环模式胶囊、右侧“清空” | 循环模式接现有播放模式事件；清空接现有队列事件 |
| 来源行 | “来自：”与真实来源标签、右侧进入箭头 | 来源不可确定时整行隐藏；不伪造歌单目的地 |
| 队列列表 | `LazyColumn`、稳定 key、约 `57dp` 行高、`44dp` 方形封面 | 长队列只滚动列表，标题区固定；非随机且至少两项时，行尾 `22dp` 点阵在独立不小于 `48dp` 的实际布局节点上长按后启动纵向拖拽 |
| 当前项 | 柔和主色容器、左侧均衡器语义、标题/歌手保持可读 | 点击仍调用现有 `playAt`；不复制播放状态 |
| 普通项 | 标题、歌手、可选时长、拖拽提示、移除 | 没有真实时长时不保留假数字 |
| 空队列 | Sheet 内简短空态 | 允许关闭；不创建演示队列 |

拖拽点阵保持确认稿的 `22dp` 可见尺寸；其实际 `48dp` 命中节点紧邻、但不与移除的 `48dp` 节点重叠，点阵本身靠尾侧对齐以保留图标位置。022 重排切片在非 Shuffle、至少两项时启用：Feature 仅以 stable id 维护临时顺序，长按点阵后垂直拖动，drop 时一次提交“将 dragged 移到 before anchor 前（没有 anchor 即末尾）”；Controller Rejected/stale、外部成员/顺序变化或 Sheet 关闭立即回到权威顺序。当前项可拖，Media3 保持当前媒体、位置和播放状态；随机播放下不排序，柄语义明确“随机播放下不可排序”，空/单项同样禁用。列表边缘静止拖动会按最新 `LazyList` 实测行几何持续自动滚动和重算目标；行点击、移除、Sheet 顶部拖拽和 Pager 横向手势不触发排序。

## 适配与无障碍

- 标准视口标题与来源区固定，列表占用剩余高度；少量条目不强行拉伸行高。
- 大字体下数量、模式和清空可换行或降为两行工具区，列表仍保留标题、歌手和移除；不得缩小系统字号。
- 封面缺失使用统一音乐占位；禁止空白块、emoji、字符画或设计稿裁片。
- 整行点击、移除和排序柄必须是三个独立语义动作；移除和排序柄触控区均不小于 `48dp`。排序柄为 TalkBack 提供“上移/下移” custom action，首末项裁减；禁用时提供准确原因而不伪造可排序状态。
- 当前项除颜色外还需提供均衡器图标或状态描述，不能只靠色彩区分。

## 设计符合度与验收

1. 以 `390 × 844dp`、Dark、`1.0×` 捕获六项队列主态，与 `08-player-queue.png` 归一化到同一画布并排、叠加检查。
2. 固定锚点覆盖 Sheet 顶边/圆角/拖拽柄、标题/数量/模式/清空、来源行、当前项背景、封面、标题/歌手、可选时长、拖拽提示和移除。
3. 补空队列、少量队列、长队列滚动与封面失败截图；现有 Player 封面和歌词基线不得因 Sheet 组件抽取发生漂移。
4. 真机验证从 MiniPlayer 和全屏播放器打开队列、选择、移除、清空、遮罩关闭、下滑关闭和系统返回优先级。
5. 重排验证覆盖当前项、跨当前项、向上/向下/末尾、Rejected/stale 回滚、外部权威变化取消、Shuffle/空/单项禁用、长按启动、边缘自动滚动和 TalkBack 上移/下移；可见点阵保持，实际 48dp 命中区为无障碍合规的必要尾部几何变化，必须经截图和 fidelity 复核，不以 golden 掩盖。
6. 截图基线存在不代表视觉自动通过；必须在相同 Sheet 裁切范围内检查确认稿与当前实现的并排、叠加和差异图，尤其复核大面积容器色与当前项层级。
