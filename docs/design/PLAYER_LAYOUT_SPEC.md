# 全屏播放器设计复刻与屏幕适配契约

状态：Accepted。确认日期：2026-08-08。适用范围：全屏播放器封面主态及其暂停、缓冲、连接中、未知时长、封面失败、空播放项和大字体状态。

本文把已确认的 [`06-player-cover.png`](mockups/06-player-cover.png) 转换为可执行的 Android 布局契约。歌词页与队列分别继续以 `07-player-lyrics.png`、`08-player-queue.png` 及已确认补充状态稿为权威，不在本切片混入主封面页。

## 权威顺序与基准语境

1. `06-player-cover.png` 决定结构、坐标、比例、间距、圆角、层级和封面裁切。
2. 本文决定设计坐标如何映射到 Compose 与系统 Insets。
3. [`DESIGN_SYSTEM.md`](../DESIGN_SYSTEM.md) 决定字体可访问性、最小触控区和禁用状态；[`13-player-artwork-palette.md`](../reference-audits/13-player-artwork-palette.md) 决定动态色语义与回退。
4. 现有播放状态和事件端口决定真实行为。收藏、下载、加歌单、分享和更多菜单在业务未接入前可以保留视觉与语义，但不得用 Toast、假状态或新持久化冒充完成。

基准画布为 `852 × 1846` 设计单位，简体中文、深色、系统字体倍率 `1.0×`、竖屏。目标逻辑宽度为 `390dp`，等比高度约为 `844.86dp`。

## 尺寸映射与 Insets

设设计画布宽度 `Dw = 852`，当前 Compact 页面容器宽度为 `W`：

```text
s = W / Dw
runtimeX = designX × s
runtimeY = designY × s
runtimeSize = designSize × s
```

- 页面所有可见尺寸使用同一 `s`，禁止横纵分别缩放、按设备型号分支或把整页截图作为背景。
- 背景绘制到系统栏后方；顶部控制消费 `statusBars`，底部操作消费 `navigationBars` / `safeGestures`，不使用固定系统栏高度。
- Medium/Expanded 没有确认稿时使用最大 `480dp` 的居中单列；封面不无限放大。
- 可见图标按确认稿尺寸绘制，点击语义区域至少 `48 × 48dp`。

### Compact 基准尺寸

- `390 × 844dp / 1.0×` 下，顶部安全区至少 `25dp`，Toolbar 为 `64dp`；封面前留白 `23dp`，封面视觉边长 `333dp`、水平边距 `28.5dp`。
- 分页指示区高 `36dp`，指示区至歌曲信息留白 `6dp`。歌曲信息与进度左右视觉锚点为 `30dp`；核心控制行使用 `22dp` 外边距，以匹配确认稿更宽的五点节奏。
- 非紧凑进度 Slider 高 `40dp`，轨道 `2dp`、拇指 `12dp`；时间标签只做 `-6dp` 视觉校正，不改变后续控件布局。
- 核心控制行高 `82dp`，主播放按钮视觉直径 `68dp`。次级动作视觉直径 `46dp`，外层仍保留 `48dp` 点击语义，顶部间距 `18dp`、动作行高 `72dp`。
- 收藏图标在歌曲信息行内做 `x +14dp / y -8dp` 的视觉校正；点击区域仍为 `48dp`，不得用缩小触控区换取对齐。

## 页面区域与所有权

| 区域 | 固定视觉 | 行为与边界 |
| --- | --- | --- |
| 沉浸背景 | 当前封面派生的深色三段渐变，封面失败时静态深色回退 | 不实时模糊，不随高频进度重算，不发额外网络请求 |
| 顶部控制 | 左侧向下收起、居中“正在播放”、右侧更多 | 收起由导航栈处理；更多业务未接入时保持视觉语义 |
| 封面与分页 | 大幅圆角方形封面、柔和阴影、两枚分页点 | 封面页为当前选中点；歌词页接入后由 Pager 状态驱动 |
| 歌曲信息 | 标题、歌手、品质徽标、右侧收藏 | 标题最多两行；品质来自真实字段或 UI 预览，收藏未接入时不伪造选中状态 |
| 进度 | 细轨道、圆形拇指、已播时间与负剩余时间 | 拖动中使用本地值，结束时只提交一次 seek；未知时长禁用 |
| 核心控制 | 随机/顺序模式、上一首、主播放暂停、下一首、循环模式 | 复用现有播放事件；缓冲与禁用态保持层级 |
| 次级动作 | 下载、加入歌单、分享、播放队列四个圆形容器 | 队列复用现有入口；其余未接入项允许视觉态，不新增假业务 |

`:feature:player` 只消费不可变 UI 状态和事件，不依赖 Media3、Service、网络、Repository、Room 或 DataStore。全屏播放器不显示一级底部导航或 MiniPlayer。

## 滚动、大字体与状态

- 基准 `390 × 845dp / 1.0×` 不滚动，所有确认稿区域在单屏内完成；只有短高窗口或内容真实溢出时启用单一纵向滚动。
- `1.5×`、`2.0×` 允许标题区域增高、封面缩小、次级动作换行或内容纵向滚动；不得缩小系统字号、裁切进度和核心播放控制。
- 无当前歌曲时显示可返回空态，不创建演示队列。连接中、缓冲、未知时长和封面失败保留当前页面结构，不以全屏 loading 取代。
- 封面使用真实资源或 Coil 已加载图片并以 `ContentScale.Crop` 裁切；缺图使用统一音乐回退。禁止 emoji、字符画、空白方块、手绘 SVG 或渐变块冒充成功封面。

## 设计符合度与验收

1. 先以 `390 × 845dp`、Dark、`1.0×` 捕获页面截图，归一化到 `852 × 1846` 与确认稿并排、叠加检查。
2. 固定锚点至少覆盖：顶部三节点、封面边界与圆角、分页点、标题/歌手/徽标/收藏、进度轨道与时间、五项核心控制、四项次级动作。
3. 固定区域边界或中心偏差不得超过 `2` 个设计单位，相邻区域累计纵向漂移不得超过 `3` 个设计单位；字体栅格、不同歌曲的真实封面内容和 Material 图标笔画只可作为遮罩差异。仅有截图存在不代表通过，必须在同画布并排和叠加中逐项确认这些锚点。
4. 设计符合度通过后才更新 Compose 回归基线。必须覆盖播放、暂停、缓冲、连接中、未知时长、封面失败、空播放项、`1.5×` 和 `2.0×`。
5. 行为验证至少覆盖收起、播放暂停、seek、上下首、模式切换、队列打开与返回优先级；未接入次级动作只验证语义和布局，不验证假结果。
