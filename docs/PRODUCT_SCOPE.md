# 产品范围

## 产品定位

MoeKoeMusic Mobile V2 是开源的第三方酷狗音乐 Android 客户端。第一版目标是覆盖桌面端用户的主要音乐使用闭环，同时提供符合 Android 平台习惯的后台播放、通知栏、锁屏、耳机和蓝牙控制体验。

“功能对齐 PC”不等于复制 PC 布局。PC 端作为功能、业务规则和品牌风格来源；Android 端重新组织信息架构与交互。

## 目标用户

- 已使用酷狗账号、收藏和歌单的用户。
- 希望使用简洁、无社交干扰的第三方客户端的用户。
- 重视歌词、播放队列、音质和后台播放体验的用户。

## 第一版功能边界

### 内容发现

- 首页推荐、每日推荐与轮播内容。
- 发现页、分类歌单、新歌、新专辑和排行榜。
- 搜索热词、建议和综合搜索。
- 歌单、专辑、歌手和排行榜详情。

### 播放体验

- MiniPlayer 与全屏播放器。
- 后台播放、通知栏、锁屏、耳机和蓝牙控制。
- 播放队列、下一首播放、移除和重排。
- 顺序、列表循环、单曲循环和随机播放。
- 音质探测、选择与降级回退。
- 同步歌词、KRC 逐字歌词、翻译与音译能力。
- 播放失败后的明确反馈与受控自动跳过。

### 账号与音乐库

- 匿名设备注册。
- 手机验证码、账号密码和扫码登录。
- 用户资料、VIP 状态和会话恢复。
- 独立用户主页：资料、关注/粉丝/好友数量、听歌概览、注册时长和公开创建歌单。
- 每日签到、领取 VIP 及可用时的概念版 VIP 升级；上游接口失效、重复领取或触发风控时提供明确反馈。
- 我喜欢、创建歌单、收藏歌单和歌单编辑。
- 收藏专辑、关注歌手和关注好友。
- 歌单歌曲添加、移除和排序。
- 用户云盘浏览与播放。
- 本地音乐扫描与播放。

### 扩展媒体能力

- MV 播放。
- 听歌识曲。
- 播放历史。
- 分享和深层链接。

### 个性化与系统体验

- 浅色、深色、纯黑主题。
- 品牌主题色和封面动态取色。
- 音质、歌词、播放和缓存设置。
- 手机优先，并为平板、横屏和折叠屏保留自适应结构。

## 实施顺序

第一版功能范围较大，开发必须按可运行的纵向闭环推进：

1. 匿名设备注册、搜索、歌曲地址解析和 Media3 播放。
2. 首页、歌单详情、MiniPlayer、全屏播放器和队列。
3. 歌词、音质、后台播放、通知栏和会话恢复。
4. 登录、用户主页、收藏与关注、用户歌单、“我的”、签到与 VIP 领取。
5. 云盘、MV、本地音乐和听歌识曲。
6. 自适应布局、性能优化和高级系统集成。

每个阶段必须可以独立运行和验证，不能先铺满空页面再集中补业务。

## 暂不承诺

- 与酷狗官方客户端完全一致的所有功能。
- 社交、评论和直播等非核心音乐功能。
- iOS、桌面或 Web 版本。
- 服务端代理和跨设备同步服务。
- 未经验证的下载、版权绕过或付费能力。

## 验收原则

- 功能成功不只指页面可见，还包括后台、网络异常、进程重建和会话恢复。
- 播放器以系统媒体规范为验收基准，不以 Activity 内能播放为完成标准。
- 酷狗接口失败必须可观察、可定位、可降级，不静默吞错。
- UI 必须覆盖加载、空数据、错误、离线和正常状态。
