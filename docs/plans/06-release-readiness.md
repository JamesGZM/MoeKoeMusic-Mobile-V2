# 阶段 6：完整能力与发布准备

## 目标

在核心闭环稳定后补齐高级媒体能力、宽屏体验和发布质量门槛。

## 实现范围

- KRC 逐字歌词、翻译、音译和时间偏移。
- 音质选择、探测、受控降级和 VIP/版权反馈。
- 用户云盘、MV、听歌识曲和深层链接。
- 平板、横屏和折叠屏的 Navigation Rail、双栏与 Supporting Pane。
- 启动、滚动、播放页动态背景和数据库性能优化。
- Release 混淆、敏感日志审计、许可证与来源文件检查。

## 测试与度量

- 歌词解析、同步、音质回退和识曲状态机单测。
- 宽屏、旋转、后台、进程重建和长时间播放设备测试。
- Macrobenchmark、Baseline Profile、Compose metrics 和内存检查。
- API 26、32、33、36 的发布回归矩阵。

## 完成标准

- 核心功能不存在仅在理想网络或前台 Activity 下可用的路径。
- 关键页面通过无障碍、大字体、深色和宽屏验收。
- Release 不输出敏感协议、账号、Cookie 或播放签名。
- 文档、ADR、许可证和实现保持一致。
