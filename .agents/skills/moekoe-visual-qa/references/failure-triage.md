# 视觉失败分流

1. **设计源或 contract 失效**：停止实现，重新确认设计基线并更新哈希。
2. **画布/裁切错误**：修 contract 的坐标空间；不得通过页面实现补偿错误裁切。
3. **固定锚点偏差**：修 Compose 几何、Insets 或统一缩放；不得扩大遮罩。
4. **可变内容差异**：确认 fixture 与状态正确，再判断是否属于已登记可变区域。
5. **字体、图标、阴影或裁图差异**：人工查看 overlay/diff，回到 Token、资源或 ContentScale 修正。
6. **仅 reference 变化**：先完成设计符合度；没有通过结果时禁止更新 golden。
7. **平台差异**：只有 Layoutlib 无法证明时进入指定真机验证，并单独报告平台证据。
